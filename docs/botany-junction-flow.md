# Woody junction flow and rounded leaf sampling

The ancestral-tree feedback identifies visible pasted branch ends, planar
transitions, insufficient large wood cords, regular bark stripes, missing
inward sockets and pointed leaves. This increment works on shared native
authoring tools and the existing ancestral study. It does not certify that all
possible artistic parameter combinations are botanical organisms.

## Native controls and compatibility

Recipe13 adds optional `OrganEdit.junction_flow: number` in [0,1]. Missing or
zero preserves the previous junction constructor. Active incident overrides
combine by maximum. Existing EditOrgan/Preview/Publish/Save/Load and the
Vegetation junction panel edit the same field. The editor and EditOrgan promote
the recipe to13; older recipes remain readable, without migrating their meshes.
Old readers reject the new recipe instead of silently discarding the field.
The global Scene and replay format versions are unchanged.

The native constructor reuses the existing bounded implicit fusion operator.
It searches a small set of central-volume proportions inside the actual collar
support domain, retains the existing face-rotation/displacement/volume guards,
and requires at least two interior refinement levels locally. A failed active
fusion is refused; it does not silently substitute a disconnected shell.

Transition cuffs follow two rings of the incident organ's actual swept surface,
including its taper and authored cords. A harmonic displacement extension fixes
both the boundary and inner cuff samples, then blends into the junction interior.
The interior is subsequently fitted toward the joined swept volumes of the
actual incident curves, including their authored radial cords and sockets. This
retains more of the wood mass than the fusion constructor's small central
sphere. A bounded radial solve respects the collar support planes; adaptive
partial movement is admitted only while sampled homotopy steps retain local
face orientation. Points without a root inside that support domain retain
their admitted seed position. This is an approximation, not a certified global
distance field or an exact boolean union.
This is a finite sampled transition, not a proof of universal C1 continuity or
arbitrary branching topology. Basal multicollars retain their existing geometric
constructor; the three-port field is not presented as a general root union.

Active junctions interpolate material coordinates from all incident boundaries
over the connected patch. This avoids assigning the entire interior to one
constant parent coordinate. Recipe13 also derives angular material drift from
positive authored wood cords, while retaining existing scar deflection. It
transports coordinates, not individual vascular strands, and does not solve a
global fibre field or guarantee its distortion bounds.

Interior material addresses include a new flow domain and the actual topology.
Changing a joint cannot silently reinterpret old interior sculpt addresses;
normal preservation/refusal policy still applies. Boundary addresses remain tied
to their organ and parameter. Living recompilation/history retain the recipe
version needed by any preserved edits.

Recipe13 woody tubes refuse a ring step that runs backwards along the local
axis tangent. This catches folded sweeps caused by combining an overly sharp
bend with a thick section, including a source of the observed flat bands. It is
a local sampled guard, not a complete self-intersection or biological-plausibility
certificate. There is no new artistic maximum trunk radius.

Rounded strip leaves already have an editable beta tip exponent. Recipe13
redistributes the existing longitudinal samples toward both endpoints when
`tip_power <= 0.5`, using a cosine map. The contour remains the same mathematical
shape; the allocation avoids a long final triangle making a rounded tip appear
as a spike. This changes neither vertex count nor the leaf topology budget.
Recipes1–12 retain their original sample positions.

## Authoring and review

`examples/ancestral-study.recipe.json` now uses connected woody forks throughout
the major scaffold, replacing the four overlapping auxiliary arms. Its primary
axes have gentler coherent curvature, large seeded cords/valleys, native inward
historical sockets and rounded white leaves. The central three forks opt into
implicit flow; distal forks retain the existing shaped-junction constructor.
The root system continues to use native rounded-root morphology.

The study's bark has wider, irregular anisotropic features and a larger bump
scale, with smaller detail kept subordinate. Large silhouette cords and deep
recesses belong to geometry. Surface bump does not create actual tunnels or
replace the remaining work on a braided central mass.

New review captures are generated directly through the native application/MCP.
The user has prohibited new automated tests and regression/verification
harnesses. This increment adds none and does not expand the existing study's
verification code. Compile/static-analysis results and direct visual observations
are recorded with the delivered study. Existing tests, CI and product admission
guards are preserved.

## Cost and remaining limits

Implicit fitting and cuff/material-coordinate preparation run during botanical
compilation, not each render frame. Coordinate relaxation is bounded to160
iterations over active joint patches, with fixed collars. It uses temporary
adjacency and coordinate buffers plus a sparse output map for those patches.
Tube and leaf vertices outside the joint retain their own local budgets. The
renderer consumes the existing material-coordinate stream; no new shader pass,
per-frame field solve, external texture or additional executable is introduced.

Swept-volume fitting uses16 cached guide segments per incident arm and32 radial
bisection steps. Arc tables are prepared once per arm, avoiding allocations in
the field query. This increases authoring/compilation cost on active joints;
it does not establish a runtime performance gain.

The changed source must still satisfy whole-plant organ/vertex/triangle and
metric precision budgets. No performance improvement, physical growth model,
global solid union, universal tangent continuity, final reference fidelity or
artistic acceptance is implied by compilation.
