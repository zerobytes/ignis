## Representation and controls

scripts/overlapping_plateaus.py authors a native closed Landform2 basal mass and
a compact seeded40-outcrop layout. Each outcrop has a target surface elevation;
full-height generation includes its walls down to ground. Existing native source,
convex-cut, extraction, material and collision operations perform all topology.
Python supplies source controls/cutter clouds and read-only verification, never
triangulation or a catalog of prebuilt meshes. One shared region/bedding remains.

The union of these overlapping solid volumes is connected. Assets remain separate
editable components: this is NOT a global Boolean union/welded manifold mesh, and
internal faces/colliders remain. Render skins each have matching cap coordinates;
per-component rock+cap coordinate edges have incidence2. No character walkthrough,
KCC seam equivalence or physics performance guarantee follows from this check.

Density knob1.10 rounds whole source-stratum counts. For seed12345, full-height
reference585strata becomes643(+9.9145%); comparison is to the same full-height
recipe at density1, not a count of every visible band in a screenshot. Relief
multiplier1.10 increases recess amplitude. Source count scales with full height
so tall walls do not dilute the layer density. Masks still suppress exposure in
some regions, preserving broad faces. Basal continuous volume uses period8/1.10m.

Critical CSG admission remains bounded3candidates. For full-height bodies, source
coordinates are normalized inY only to select proportional detail-cut controls;
the resulting convex cloud is mapped back and native CSG evaluates the real mesh.
This is an authoring-coordinate operation, not Python-built mesh topology.
