# Living giant sequoia exemplar

The `sequoia` exemplar is generated by native Rust grammar5, not an imported mesh or a Python geometry generator. Its definition is in `examples/sequoia.recipe.json`. The editable birth-state asset is `assets/botany/sequoia.ignis-botany`; the current thousand-year scene and native captures are under `artifacts/sequoia/`.

Run `python3 scripts/demo_sequoia.py` to regenerate the review and `python3 scripts/open_sequoia.py` to open the native editor. The launcher accepts `--years N`. Vegetation → Load exemplar/source → Living giant sequoia also creates the birth state. The selected specimen has the existing reversible age preview, with an initial slider range of 0–3000 years. One year is 365 game days; changing the preview does not rewrite the saved tree or its interventions.

## Reference and approximation

Species: **Sequoiadendron giganteum**, not coastal redwood. The reference architecture is a dominant massive reddish trunk, a conifer crown, fine scale-bearing branchlets, and a higher crown in old specimens. [USDA Silvics](https://www.srs.fs.usda.gov/pubs/misc/ag_654/volume_1/sequoiadendron/giganteum.htm) describes mature trees commonly around 76m tall, substantial trunk diameters, and lower-branch loss. [Flora of North America](https://www.efloras.org/florataxon.aspx?flora_id=1&taxon_id=210002083) distinguishes young conical crowns from older, more rounded crowns.

These observations guide an authored exemplar, not a fitted botanical growth model. A chosen age does not establish the age of a reference photograph. Individual tiny scales are aggregated into closed geometric sprays, each made of three narrow blades; their organ IDs and dimensions describe the aggregate, not a giant individual leaf. Fine branchlets have closed separate sheath connections, while selected widely spaced structural limbs have continuous graft junctions. This is an explicit geometric approximation, not a claim of fused vascular topology throughout the crown.

## Growth model

Grammar1–4 outputs are preserved. Grammar5 is an explicit species grammar using the existing optional `continuous` and `foliage` profile fields; older readers reject it. No global scene/replay format change is required.

For age `a` in years, height uses the existing independent rational law:

`H = H0 + (Hlim-H0) a/(a + tH/19)`.

Diameter uses a cubic rational law in cross-sectional area, avoiding the very large juvenile diameters produced by an unmodified linear area fraction with giant-tree parameters:

`D² = D0² + (Dlim²-D0²) [a/(a+tau)]³`.

With `D95 = D0 + .95(Dlim-D0)` and `f95 = (D95²-D0²)/(Dlim²-D0²)`, `tau = tD(f95^(-1/3)-1)`. Thus the reference age still means 95% of the diameter increment. Both dimensions approach their limits smoothly and keep increasing at finite ages. Defaults are H0=.6m, Hlim=85m, tH=1200y, D0=.04m, Dlim=8.5m, tD=3000y. These are authoring values, not measured annual growth rates. The diameter is the model's trunk-base diameter, not field-measured DBH.

Seed controls azimuths, asymmetry, branch extension, sprays and procedural bark. Sixteen persistent main sites emerge at one-year intervals, each carrying three azimuthally distributed limbs. Their descendants follow a finite three-order scaffold. Relative branch lengths follow a tapered crown envelope; old limbs turn upward more. The lowest third of sites progressively reduce their sprays between 150 and 300 years and are omitted at 300 years; this intentionally simple architectural transition is not simulated shading, carbon balance, deadwood decay or wind breakage. The apex has foliage from the birth state.

Sequoia reproduction must have all angiosperm flower/fruit durations zero. The validator rejects flowering/red-fruit schedules for this grammar. **Cones are not implemented in this exemplar.** The existing reproduction system and its other species remain unchanged. Foliage-profile counts and dimensions control aggregate sprays; grammar4's metric node emergence and turnover are not applied to grammar5. The shared profile's internode and turnover fields are retained for compatibility but are not a sequoia leaf-cohort simulation.

Bark is a deterministic native runtime procedural material with longitudinal grain, high roughness and bump. It does not add geometric furrows or use photographs. Existing native wind/physics experiments are separate from automatic gameplay growth.

## Validation

The unit coverage evaluates birth, 1/5/20/100/300/1000/3000 years, native bake, serialization, persistent pruning, reference-diameter math and continued old-age growth. The review script exercises the actual release executable over MCP, captures each stage, tests reversible 5→1000→5 preview without changing canonical state, and requires byte-identical PNG after save/reopen. `verification.json` records generation command wall time; it is not a frame-time or FPS measurement. Human visual acceptance remains separate.

The reviewed release (`a10bed0aee4e0581`) produced 35,459 organs at 1000 years, with trunk-axis height 79.986m and base diameter 7.329m. The native MCP advance command took about 2.88s for this mature stage in the review run, including validation and rebuilding; it is not a runtime frame measurement. Six growth unit tests and release Clippy for the library/binary passed. The prior grammar4 saved scene also rendered byte-identically to its existing PNG. Native editor PID48556 was opened with the thousand-year scene and visible 0–3000-year slider; existing windows were preserved. This first exemplar still has an authored regular scaffold and approximate bark/sprays; the native captures are the visual review, not photorealistic or botanical acceptance.
