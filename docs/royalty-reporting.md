# Private royalty reporting

[LICENSE](../LICENSE) controls. This page is an operational template, not a public
financial disclosure form. Do not post reports, tax identifiers, bank details,
player records or payment credentials in GitHub issues or pull requests.

Before the first USD 1,000,000 lifetime Game revenue, no routine report or
registration is required. Keep records supporting revenue and eligible costs.
After exceeding the threshold, submit a report and any payment due within 60
days after each calendar quarter while the Game earns revenue or has payment due.

Request a private reporting channel through the maintainer contact route on
[Guilherme Oliveira's project profile](https://github.com/zerobytes). No payment
processor, invoice system or bank recipient is implied by the existence of this
repository. Use only privately agreed, verified instructions.

## Suggested private report fields

| Field | Contents |
| --- | --- |
| Responsible party | Developer/business name and a private contact |
| Game | Title, stable identifier and relevant stores/platforms/editions |
| Period | Calendar quarter and currency conversion sources/dates |
| Revenue | Lifetime total, quarter total, exemption used and remaining |
| Threshold split | Date/quarter crossing the threshold; split receipts and cost allocation method |
| Eligible costs | Documented categories, shared-cost allocations and adjustments |
| Opening loss | Unrecovered Game loss when the revenue threshold was reached |
| Profit balance | Cumulative post-threshold receipts minus eligible costs and Opening Loss |
| Calculation | Eligible Profit, 1% cumulative royalty, prior payments/credits and current payment |
| Corrections | Refunds, chargebacks or corrections to an earlier report, counted once |

A zero-profit quarter has a zero payment. Keep losses and credits in the
cumulative calculation. Preserve records for five years as specified in LICENSE.
The license's limited audit process is confidential and Game-specific.
