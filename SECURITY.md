# Security policy

Ignis is pre-1.0 research software. The latest public `main` is the supported
reporting target; there is no maintained security backport branch or response
time guarantee. Treat untrusted scenes, assets and network peers cautiously.

Please report exploitable vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/zerobytes/ignis/security/advisories/new).
Include the affected revision, platform, minimal reproduction, impact and
suggested mitigation if known. Do not include live secrets or personal data.

If the private reporting form is unavailable, use the maintainer's GitHub
profile contact options to request a private channel before sharing details.
Do not put an exploit or confidential data in a public issue. Ordinary crashes
without a security impact can use the bug report template.
