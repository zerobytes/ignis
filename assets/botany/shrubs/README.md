# Arbustos procedurais

8 famílias,24 variações e42 fontes `.ignis-botany`7. Compactos densos, abertos,
espalhados, verticais, de folhas grandes e flores brancas/rosas/amarelas.

Cada corpo reúne madeira e folhas em uma fonte, usando os dois materiais nativos.
Pétalas e miolos usam fontes adicionais; `library.json` descreve cada conjunto.

```sh
python3 scripts/shrub_assets.py
python3 scripts/demo_groundcover.py --collection shrubs
```

O gerador substitui explicitamente as fontes desta pasta. Salvar esculturas e
customizações em outro destino antes de regenerar.

[Uso, densidade e limites](../../../docs/shrub-assets.md).
