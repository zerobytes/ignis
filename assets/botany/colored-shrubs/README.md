# Arbustos de folhagem colorida

Quatro referências reais, três variações por perfil e24 fontes nativas7:
pingo-de-ouro, Berberis vinho, loropétalo roxo e Cotinus roxo. Aproximações
procedurais autorais, sem fotos como textura ou geometria.

Cada variação tem corpo (madeira + folhas maduras) e brotação menor/mais clara.
`library.json` reúne os componentes. As cópias exportadas compartilham geometria.

```sh
python3 scripts/colored_shrub_assets.py
python3 scripts/demo_groundcover.py --collection colored-shrubs
```

Regenerar substitui estas fontes. Preserve esculturas/customizações em outro
destino. [Referências, uso e limites](../../../docs/colored-shrub-assets.md).
