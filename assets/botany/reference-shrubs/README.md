# Arbustos das sete referências

Oito perfis,24 variações e48 fontes `.ignis-botany`7: moitas desérticas cinzentas,
baixas/lobadas, cabeças claras, copas ovais, folhas estreitas, topiarias de folha
miúda, esferas folhosas e arbustos verticais densos. Nomes descritivos, sem
identificação científica pelas fotos.

```sh
python3 scripts/reference_shrub_assets.py
python3 scripts/review_reference_shrubs.py
python3 scripts/demo_groundcover.py --collection reference-shrubs
python3 scripts/present_reference_shrubs.py
```

Curvas, folhas, brotação e cabeças discretas são procedurais. Nenhuma fotografia
é textura ou fonte de vértices. Regenerar substitui estas fontes; preserve suas
esculturas/customizações em outro destino.

[Uso, referências, evidências e limites](../../../docs/reference-shrub-assets.md).
