# Mato alto procedural

8 arquétipos,24 variações e39 componentes de cor em fontes editáveis
`.ignis-botany`7. Inclui capim denso/recurvado, caniços, juncos com espigas,
plumas altas, macega seca e matos ramificados com/sem flores.

Gerador: `python3 scripts/tallgrass_assets.py`. Regenerar substitui explicitamente
as fontes desta pasta; salvar esculturas/customizações em outro destino.
Manifesto: `library.json`. A coleção baixa aprovada permanece independente.

Compilação e galeria: `python3 scripts/demo_groundcover.py --collection tallgrass`.
Plantio compartilhado: `scripts/plant_groundcover.py --collection tallgrass`.

[Uso, porte e custos](../../../docs/tallgrass-assets.md).
