# Editable marble material sources

Twelve artistic families: Verde Breccia, Emerald White/Gold, Emerald Gold,
Carrara, Calacatta, Statuario, Nero Marquina, Portoro, Emperador, Rosso Levanto,
Rosa and Azul. All source pixels come from seeded native fields; no photograph
is embedded. The names describe authoring presets, not certified quarry origin.

Load a `.ignis-material` onto an existing mesh through the material library in
the editor or the `material/load` MCP operation. Edit the palette, fracture,
strata, grain and finish controls; keep runtime evaluation or explicitly bake
fixed maps up to 1024. These compact files retain editable runtime sources.

See [the marble contract and native gallery workflow](../../../docs/marble-materials.md).
